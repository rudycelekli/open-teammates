# Example missions

These briefs are fictional and supply no venue availability, vendor prices, attendee commitments, approvals, or historical performance. They are starting inputs for the local drafting workflow.

```sh
open-teammates run --brief examples/developer-flagship.json --dir .teammates
open-teammates run --brief examples/executive-program.json --dir .teammates
open-teammates run --brief examples/webinar.json --dir .teammates
```

Each run generates an executive event brief, portfolio strategy, exact budget allocation, production run of show, risk register, stakeholder plan, measurement plan, and follow-through plan. All outputs remain proposals. Budget allocations are integer major currency units with a reserved contingency inside the ceiling; they are not supplier quotes.

Replace the audience promise and constraints first. Then verify date, location, timezone, staffing, price, permission, and local requirements with the responsible people. Use the generated artifacts to make those decisions concrete.
