# Changelog

## 0.2.0

- `hire chief-of-events` installs Mira's role bundle and work ledger, with an optional fictional assignment or supplied brief. Existing role edits are preserved.
- Project-local `connect` emits MCP configuration and role instructions, preserves unrelated servers, and refuses conflicting or linked paths.
- Official-SDK stdio MCP server with twelve bounded local work tools, explicit personality/work-contract resources and a role-loading prompt. Tools do not call a model, approve handoffs or execute external actions.
- Event-relative task graphs with timezone-aware deadlines, prerequisites, accountable owners, completion evidence, advisory readiness and post-event follow-through.
- Brief and artifact versions, retained history, stale-write conflicts, superseded mission handoffs, atomic state writes and cooperative single-host process locking with guarded stale-owner recovery.
- On-demand work briefings, proposed decisions, sourced reported outcomes, owner-reviewed memory and consultation context scoped to the current mission revision.
- Executable eight-case judgment evaluation pack with matched baseline/Mira requests, offline plans, explicit single-case live opt-in, retained usage/timing/failures, separate grader notes and independent human-review summaries. Missing scores remain incomplete; critical failures override averages.
- Pinned MCP SDK and Zod dependencies, dependency lockfile, and verification with the official SDK client against real stdio and a real CLI subprocess. Tests also cover competing processes, draft conflicts, onboarding preservation, authority boundaries and mocked provider failures.

Public MIT-licensed GitHub foundation. npm registry publication, real-provider benchmark scores, end-to-end deployment in a selected agent host and professional event-delivery outcomes remain unverified. Passing tests establishes local behavior and protocol plumbing, not world-class judgment or autonomous leadership.
