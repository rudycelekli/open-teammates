# Runtime decision

Checked against primary sources on October 7, 2026. Open Teammates is an independent MIT-licensed project. It is not affiliated with OpenAI, Nous Research, OpenClaw, Maria Gorskikh, Merit Systems, or Anil Matcha. A job description inspired the first role; it does not establish an endorsement or employment relationship.

The foundation is a portable role package, with a small Node CLI and an inspectable local workspace. Shared personality DNA, role instructions, skills, artifact templates, evaluation cases and permission decisions belong to this project. Execution and account connections belong to the selected host. We do not copy upstream implementations or combine several complete runtimes into one process.

Hermes is the first recommended host for an ongoing teammate: it documents profiles, persistent memory, skill learning, delegation, scheduling and messaging. OpenClaw is the alternative for an operator already using its gateway and channels. The local Open Teammates experience makes the role reviewable without installing either host. A one-line CLI installation cannot supply provider credentials, vendor access, or prove executive-level judgment.

These are source snapshots for reproducible review, not dependency pins: no upstream runtime code is bundled or installed by Open Teammates. Marketing claims and reported upstream test counts were not reproduced here.

## Export contract

`exportRuntime({ runtime, out, force })` creates an export directory with the shared DNA merged into `SOUL.md`, plus `AGENTS.md`, `IDENTITY.md`, `role.json`, `skills/chief-of-events/SKILL.md`, and an `INTEGRATION.md` explaining the receiving host’s responsibilities. The default refuses an existing destination. Explicit `force` rewrites only export files and preserves unrelated files. Export never reads secrets or edits a running host’s configuration.

| Adapter | Additional output | How the operator uses it |
| --- | --- | --- |
| `generic` | None | Review and manually load operating instructions in a compatible host. |
| `hermes` | `distribution.yaml`, minimal `config.yaml` | `hermes profile install /absolute/export --name chief-of-events --alias`; run setup, then launch `hermes -p chief-of-events chat` from the export directory so project instructions load. |
| `openclaw` | None | `openclaw agents add chief-of-events --workspace /absolute/export` on a configured host, using a new agent ID. |
| `pi` | `system-prompt.md` | `pi --append-system-prompt /absolute/export/system-prompt.md --skill /absolute/export/skills/chief-of-events`. |
| `open-dots` | `bot.json` | Manual import: review the payload and use the host’s authenticated persona API/UI. No request is sent by exporting. |
| `open-instinct` | `PERSONA.md` | Manual merge into Maria’s initialized data directory and skills folder. Merit’s code requires a separate adaptation. |

The [Hermes distribution specification](https://github.com/NousResearch/hermes-agent/blob/7583a6610ef7226a3dfc1d6721582210d742754a/website/docs/user-guide/profile-distributions.md) accepts a local directory with `distribution.yaml` and installs SOUL and skills into the profile. We omit model assumptions, secrets, MCP servers and scheduled jobs. [Context-file documentation](https://github.com/NousResearch/hermes-agent/blob/7583a6610ef7226a3dfc1d6721582210d742754a/website/docs/user-guide/features/context-files.md) establishes that SOUL comes from HERMES_HOME while AGENTS is discovered from the working directory. The distribution guide says git-ref install pinning is still planned; do not advertise `#v1` install syntax as supported.

[OpenClaw workspace documentation](https://github.com/openclaw/openclaw/blob/a6e31e2247ebdc477be43c8ba6b5e73bf6082928/docs/concepts/agent-workspace.md) defines SOUL, AGENTS, IDENTITY and workspace skills. [Its agent CLI](https://github.com/openclaw/openclaw/blob/a6e31e2247ebdc477be43c8ba6b5e73bf6082928/docs/cli/agents.md) documents adding a new agent with an explicit workspace. Files in a workspace do not by themselves enable isolation. [Experimental Claws documentation](https://github.com/openclaw/openclaw/blob/a6e31e2247ebdc477be43c8ba6b5e73bf6082928/docs/cli/claws.md) is a future packaging option, after that contract stabilizes.

[Pi’s CLI contract](https://github.com/earendil-works/pi/blob/eb326d265ae0b88489a6d10319307780df827cdf/packages/coding-agent/docs/cli.md) supports appended system-prompt files and explicit skill directories. [Its skills documentation](https://github.com/earendil-works/pi/blob/eb326d265ae0b88489a6d10319307780df827cdf/packages/coding-agent/docs/skills.md) uses the portable Agent Skills frontmatter and progressive loading. No global package/settings change is needed for the exported invocation.

[Open Dots’ bot router](https://github.com/Anil-matcha/open-dots/blob/0a4ff9574ee29f8c0adcd39018f393a65fb2dde7/server/app/routers/bots.py) accepts name, role, description, avatar, model, accent_color, system_prompt and tools. We omit model so the configured host default applies, omit server-owned IDs and timestamps, and supply an empty tools list. That payload does not configure provider credentials or connector access. [Maria’s customization guide](https://github.com/mariagorskikh/open-instinct/blob/a4df7eea61a9c6dd824901e5c8068db2d89ecda6/docs/CUSTOMIZE.md) defines PERSONA.md, AGENTS.md and a single skills-directory override; existing host policies must remain intact.

## What makes this a teammate

Personality is one layer. A useful employee also needs role workflows, context, artifact ownership, explicit authority, real account bindings, evidence of action, and evaluation against demanding scenarios. Version 0.2 ships local hiring, a durable work ledger and twelve bounded MCP tools for host-driven planning. The [host connection contract](HOST-INTEGRATION.md) separates local work from owner approval and external execution. Future integrations need verified inputs, host-enforced spending and communication rules, action receipts, idempotency and recovery, then supervised evaluation of actual event operations. Prompt text alone cannot enforce those boundaries or establish world-class performance.
